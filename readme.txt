Choropleth for Leaflet Map

## Description

Code for using the <a href="https://github.com/timwis/leaflet-choropleth">Choropleth</a> plugin for Leaflet (color scale based on value) in WordPress

## Installation

This plugin needs Extensions for Leaflet Map version > 5.4 or its Github version > 5.4-260808.

Download the <a href="https://github.com/hupe13/choropleth-leaflet-map/archive/refs/heads/main.zip">zip file</a> from Github and <a href="https://wordpress.org/support/article/managing-plugins/#manual-upload-via-wordpress-admin">upload it via WordPress Admin</a>.
Activate the plugin. Prerequisites are <a href="https://wordpress.org/plugins/leaflet-map/">Leaflet Map</a> and <a href="https://wordpress.org/plugins/extensions-leaflet-map/">Extensions Leaflet Map</a>.
Go to Settings - Leaflet Map - Extensions for Leaflet Map - Choropleth Map and get documentation and settings options.
